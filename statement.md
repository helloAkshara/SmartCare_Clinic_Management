# 📋 Project Statement

## Project Title

**SmartCare – Clinic Management & Rule-Based Triage System**

## Problem Statement

Managing patient details, doctors, appointments, and medical records manually can be difficult and time-consuming.

SmartCare provides a simple Java-based system to manage these clinic activities in one place. It also includes a rule-based triage simulation to assign a priority level based on selected symptoms and their severity.

## Scope

The project includes:

- Patient management
- Doctor management
- Symptom-based triage
- Appointment booking
- Medical records
- Patient history
- Daily reports
- Input validation and error handling

The triage system is an educational simulation and does not provide medical diagnosis.

## Target Users

- Clinic staff
- Doctors
- Clinic administrators
- Students learning Java

## High-Level Features

- 👤 Register and manage patients
- 👨‍⚕️ Register and manage doctors
- 🩺 Perform rule-based triage
- 📅 Book appointments
- 📋 Manage medical records
- 📊 Generate daily reports

## Expected Outcome

The project provides a functional Java-based clinic management application while demonstrating important Java concepts such as **Object-Oriented Programming, Collections, File Handling, Exception Handling, and Input Validation**.
